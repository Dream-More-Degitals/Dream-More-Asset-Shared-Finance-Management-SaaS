# D-AssetPro
## Dream More Asset & Shared Finance Management SaaS

D-AssetPro is a role-based Asset and Shared Finance Management SaaS platform designed to help organizations manage assets, finances, shareholders, investments, procurement, and reporting in a centralized system.

The system provides transparency, automation, and data-driven decision-making through financial analytics, AI-powered insights, and offline support using Progressive Web App (PWA) technology.

---

# Project Vision

To create a modern enterprise management platform that simplifies asset management, improves financial transparency, automates reporting, and supports better decision-making.

# Development Workflow

The project follows a Git-based workflow.

## Branch Structure

```
main
 |
 └── develop
      |
      └── feature branches
```

### Main Branch
- Production-ready code only.
- No direct commits allowed.

### Develop Branch
- Main integration branch.
- Completed features are merged here after review.

### Feature Branches

Format:

```
feature/feature-name
```

Examples:

```
feature/frontend-layout
feature/dashboard
feature/asset-module
feature/finance-module
```

# Team Development Rules

- Each member works on their assigned feature branch.
- Before starting work, pull the latest changes.
- Do not directly push to main.
- Use clear commit messages.
- Create Pull Requests before merging.

Example commit messages:

```
Create dashboard KPI cards

Implement asset management page

Add finance module UI
```

Avoid:

```
update

changes

test
```
